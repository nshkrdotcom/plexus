# Graph and subtrees

Plexus keeps a lightweight in-memory graph so semantic populations can be inspected and pruned.

## Stored metadata

- actor id
- module
- parent
- children
- labels/metadata
- run id

## Why a graph exists

TypeSafe gives semantic execution. Plexus adds population structure.

That enables:

- root/child organization
- subtree cancellation/pruning
- future visualizers
- future scoring/aggregation passes
